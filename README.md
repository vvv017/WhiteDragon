# 白龍 WhiteDragon

A customizable expression-avatar userscript for ChatGPT.

WhiteDragon adds a character portrait beside ChatGPT replies and can switch expressions **while the response is still streaming**. It also supports per-Project avatar packs, sticky portraits for long replies, interface renaming, and live layout controls.

> Current release: **4.4.0**

## Features

- 10 built-in expression states:
  `neutral`, `smile`, `laugh`, `confused`, `annoyed`, `serious`, `surprised`, `sad`, `smug`, `thinking`
- Real-time expression switching during ChatGPT streaming
- Hidden `[[avatar:...]]` control markers
- Per-ChatGPT-Project avatar packs with fallback to the default pack
- Sticky avatar that follows long replies and stops at the end of the message
- Only one assistant avatar visible at a time
- Adjustable avatar size, horizontal position, vertical offset, and sticky height
- Draggable settings panel
- Custom ChatGPT display name, prompt text, header font, and header color
- Local-only image storage through IndexedDB
- High-quality image import with transparency preserved
- No OpenAI API key required
- No extra model requests generated by the userscript

## Install

1. Install a userscript manager such as **Tampermonkey** or **Violentmonkey**.
2. On Chromium-based browsers, make sure the extension is allowed to run userscripts.
3. Install `whitedragon.user.js`.
4. Reload ChatGPT.
5. Click the **♥** button in the lower-right corner.
6. Import your avatar images.

### Required image filenames

WhiteDragon recognizes these filenames:

```text
neutral.png
smile.png
laugh.png
confused.png
annoyed.png
serious.png
surprised.png
sad.png
smug.png
thinking.png
```

PNG is recommended, especially for transparent character art.

## Expression markers

WhiteDragon uses markers such as:

```text
[[avatar:thinking]]
```

A reply can contain multiple markers:

```text
[[avatar:neutral]]

The room is quiet.

[[avatar:thinking]]

Something feels strange...

[[avatar:surprised]]

Wait—what was that?

[[avatar:laugh]]

Never mind. Mystery solved.
```

While ChatGPT is streaming, each newly completed marker immediately switches the avatar to the newest expression. Marker-only lines are hidden by the userscript.

Markers inside code blocks are ignored.

## Recommended ChatGPT instruction

Copy the prompt from [`CUSTOM_INSTRUCTIONS.md`](CUSTOM_INSTRUCTIONS.md) into your ChatGPT custom instructions or Project instructions.

The script still has a basic text-based fallback when no marker is present, but explicit markers provide the best results.

## Project-specific characters

Open a conversation inside a ChatGPT Project, click **♥**, and import images there.

WhiteDragon stores that Project's expression pack separately. Missing Project expressions automatically fall back to your default pack.

This lets you use different characters or costumes for different Projects without changing the marker protocol.

## Interface customization

The settings panel can also customize:

- `ChatGPT Pro` → e.g. `Alice Pro`
- `Ask ChatGPT` → e.g. `Ask Alice`
- Header font family
- Header text color
- Avatar size and position
- Sticky screen height

The panel itself can be dragged out of the way while previewing changes. Double-click the panel header to re-center it.

## Privacy

WhiteDragon runs locally in your browser.

- Avatar images are stored locally in IndexedDB.
- UI preferences are stored locally.
- The script does not contain an OpenAI API key.
- The script does not send additional prompts or model requests.
- No analytics or telemetry are included.

The `[[avatar:...]]` markers are generated as part of the normal assistant reply, so they add a very small amount of text to the conversation.

## Compatibility

WhiteDragon currently targets:

- `https://chatgpt.com/*`
- `https://chat.openai.com/*`

ChatGPT is a frequently changing web application. DOM changes may occasionally break UI detection. If that happens, please open an issue with:

- browser name/version
- userscript manager/version
- WhiteDragon version
- screenshot
- console error, if available

## Development

